# Cloud Storage Explorer - Codtech Intern Task 1# Cloud Storage Explorer - Codtech Intern Task 1
By Sailaja | Python Cloud Project

## Overview
This project is a Cloud Storage Explorer that simulates AWS S3 bucket operations. It allows users to explore cloud storage like a real cloud console.

## Features Implemented
- List all files in cloud bucket with size
- Upload file to cloud storage
- Download and view file content
- Delete file from cloud
- Create folder in cloud storage

## Technology Used
- Python 3
- OS module for file handling (Local simulation of cloud)
- Boto3 ready structure - can easily connect to real AWS S3, Google Cloud, Azure Blob
