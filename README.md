# Cloud-Based Database - Codtech Intern Task 1
By Sailaja | Python Cloud Database Project

## Overview
This project is a cloud-based database management system. It demonstrates how to create, connect, and manage a database on the cloud like AWS, GCP, or Azure. This simulates real cloud database operations using Python.

## Features Implemented
1. Connect to Cloud Database Instance (Simulated)
2. Create Database and Table in Cloud
3. Insert Data into Cloud Database
4. Read/Query Data from Cloud Database
5. Update Data in Cloud Database
6. Delete Data from Cloud Database
7. Cloud Database Status Monitoring

## Technology Stack
- Python 3
- SQLite3 (Simulates Cloud MySQL/PostgreSQL Engine)
- datetime module
- Ready to migrate to real Cloud using: boto3, pymysql, psycopg2
- AWS/GCP/Azure Compatible Structure

## How to Run

### Step 1: Clone the Repository
git clone https://github.com/injarapusailaja123-blip/cloud-based-database.git
cd cloud-based-database

### Step 2: Install Python (if not installed)
Download from python.org - Python 3.8+ required

### Step 3: No Extra Installation Needed
This project uses only built-in libraries:
- sqlite3 (comes with Python)
- datetime (comes with Python)

### Step 4: Run the Application
python app.py
OR
python3 app.py

### Step 5: Output You Will See
- Connecting to Cloud Database...
- Cloud Database Status: Available
- Table creation successful
- Data insertion (3 records)
